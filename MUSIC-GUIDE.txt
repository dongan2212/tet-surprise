🎵 HOW TO ADD BACKGROUND MUSIC 🎵
================================

Your romantic Tet website supports background music!

STEP 1: Find Music
-------------------
Search for: "Vietnamese Tet instrumental" or "romantic piano instrumental"

Recommended free sources:
- YouTube Audio Library: https://studio.youtube.com/channel/UC/music
- Free Music Archive: https://freemusicarchive.org
- YouTube (use a converter): https://ytmp3.cc

STEP 2: Download as MP3
------------------------
Make sure it's in MP3 format (.mp3 file extension)

STEP 3: Rename the File
------------------------
Rename your music file to exactly: tet-music.mp3

STEP 4: Place in Website Folder
---------------------------------
Put "tet-music.mp3" in the same folder as index.html

Like this:
tet-website/
├── index.html
├── tet-music.mp3  ← Your music file here
├── images/
└── videos/

STEP 5: Test It!
-----------------
1. Open index.html in your browser
2. Enter the password
3. Click the music button (bottom right corner) 🎵
4. Music should play!

TIPS:
-----
✓ Keep the music file under 10MB for faster loading
✓ Choose instrumental music (no lyrics) for a romantic feel
✓ Soft piano, violin, or traditional Vietnamese instruments work best
✓ Songs should be 3-5 minutes long (will loop automatically)

RECOMMENDED SEARCH TERMS:
-------------------------
- "Vietnamese spring instrumental"
- "Romantic piano love song instrumental"
- "Traditional Vietnamese music instrumental"
- "Soft romantic background music"
- "Chinese New Year instrumental music"

TROUBLESHOOTING:
----------------
If music doesn't play:
1. Make sure file is named exactly "tet-music.mp3"
2. Make sure it's in the same folder as index.html
3. Try clicking the music button again
4. Check browser console for errors (F12)
5. Some browsers block autoplay - user must click the button

NOTE: The website works perfectly WITHOUT music too!
The music is optional but adds a lovely romantic touch. 💕
